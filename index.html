Threads API

Operated by Yuhda Ibrahim

Threads API is a small automation tool that uses Meta's Threads API to search public posts by keyword, for example to help small businesses (UMKM) in Indonesia see what people are talking about on topics such as food. It runs as an automated workflow and has no public sign-up or user accounts of its own.

What the app does

A person operating the workflow enters a search keyword, and the app asks the Threads API for matching public posts. Results are shown to the operator and are not published, sold or shared with third parties.
